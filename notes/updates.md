## 3. Python "Scripting" Horrors                                                                                                
                                                                                                                                
 src/tmdb.py  is a textbook example of "AI Code."                                                                               
                                                                                                                                
• Infinite Recursion: You handle 429 (Rate Limit) by calling the function again after 1 second. If the rate limit persists or
